# 自选看盘小组件

一个轻量的 Windows Tauri 小窗：单页自选看盘、约 0.1 秒行情推送、价格上下穿越提醒、托盘隐藏。行情由本机桥接服务读取，避免把行情请求直接暴露给页面。

## 第一次运行

在“x64 Native Tools Command Prompt for VS 2022”（或已加载 `VsDevCmd.bat` 的终端）执行：

```powershell
cd C:\Users\34541\Desktop\stock-widget-tray
python -m pip install akshare
npm install
npm run tauri dev
```

如果 Rust 报 `link.exe` 或 `kernel32.lib` 缺失，需要安装 Visual Studio Build Tools 的 C++ 工具和 Windows SDK，然后重新打开终端。

## 使用

- 在底部输入 6 位代码后会先校验行情源；只有能查到名称的有效代码才会加入自选。
- 每行显示现价、涨跌额、涨跌幅、开盘、最高、最低和最近 3 秒动能。
- 在股票行从右向左拖动超过约 90px 可移除标的。
- “涨到 / 跌到”勾选后填写目标价，触发时仅发送 Windows 系统通知，不显示软件内弹窗。
- 每只股票可分别勾选“涨到目标价提醒”和“跌到目标价提醒”，填入价格后保存；达到阈值会发送一次系统通知，价格回到阈值另一侧后再次穿越才会重新提醒。
- 点击右上角“收进托盘”隐藏窗口；托盘图标左键可再次显示，右键菜单可退出。
- 自选列表保存在浏览器本地存储中，最多 20 只。

## 行情说明

行情桥接服务在交易时段按约 0.1 秒批量请求全部自选股，并通过本地 SSE 增量推送到页面；页面不再高频轮询，也不会在每次报价时重建 DOM 或写入 localStorage。批量主链路使用新浪实时行情接口，新浪失败时切换腾讯批量接口，AKShare 的逐只接口只作为网络异常时的异步兜底。非交易时段自动降到 15 秒一轮。行情服务地址为 `http://127.0.0.1:8765/quotes`，推送地址为 `http://127.0.0.1:8765/stream`。

界面中的“动能”不是交易所原生字段，而是客户端根据连续行情计算的短线价格变化率（约 3 秒窗口），用于观察即时方向，不等同于成交量或技术指标结论。

程序使用 Windows 命名互斥锁保证单实例；退出时会回收由程序启动的 Python 行情桥接进程，避免旧版本服务占用 8765 端口。

当前开发版启动依赖本机 Python 和 AKShare。系统预警使用 Rust 端的 Tauri Windows 通知插件；如果 Windows 通知被系统关闭，需要在系统通知设置中允许本程序。正式分发时需要再用 PyInstaller 把 `src-tauri/resources/server.py` 及其 Python 运行时打成 sidecar，才能做到目标机器免安装 Python。
